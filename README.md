# Apple Favorite — Цифровые сервисы (Telegram Mini App)

Фирменный стиль Apple Favorite: логотип, синий акцент #0071e3, фон #f5f5f7 (как на rogday.ru),
тёмная тема включается сама по теме Telegram.

Мини-приложение магазина цифровых товаров: подарочные карты (Apple, PlayStation,
Xbox, Roblox, Fortnite), подписки (Telegram Premium, Discord) и установка приложений,
удалённых из российского App Store. Статический сайт — без сборки и бэкенда,
открывается в Telegram, светлая/тёмная тема подстраивается под Telegram.

```
index.html        разметка (экран, панель покупки, нижнее меню, шторка)
css/app.css       стили, темы
js/config.js      бренд, менеджер, бот, цены на установку приложений
js/data.js        каталог: карты, приложения, тексты инструкций и документов
js/icons.js       логотипы брендов для карт (tools/build-icons.cjs, Simple Icons, CC0)
js/ui-icons.js    иконки интерфейса (tools/build-ui-icons.cjs, Phosphor Icons, MIT)
js/app-icons.js   пути к иконкам приложений (tools/apply-app-icons.cjs)
img/apps/         иконки приложений (42 из 53)
js/app.js         логика: вкладки, выбор, корзина-панель, оформление, заказы, рефералы
```

## Что настроить перед запуском

1. `js/config.js` — название, `managerUsername` (кому уходят заказы), `botUsername`
   (для реферальной ссылки), цены на установку приложений.
2. Реферальная ссылка: в `botUsername` впишите реального бота, а если создали Mini App через
   @BotFather (`/newapp`) — его короткое имя в `appShortName`, тогда ссылка откроет сразу приложение.
3. `js/data.js` — цены на карты и подписки (сейчас ориентиры), список приложений,
   **тексты оферты и политики конфиденциальности** (сейчас заглушки).
4. Иконки приложений: для 42 из 53 стоят настоящие (из App Store или с официальных сайтов),
   остальные — нарисованные плитки в фирменных цветах (VK Мессенджер, VK Музыка, Почта Mail,
   Лента, Банк Авангард, Новиком, Россельхозбанк, СОГАЗ, Сургутнефтегазбанк, СберКидс,
   ВТБ Инвестиции). Чтобы заменить любую — положите `img/apps/<имя>.webp` и запустите
   `node tools/apply-app-icons.cjs`. Если у вас есть оригиналы PNG — положите их в ту же папку.
   Это товарные знаки их владельцев; используются для того, чтобы покупатель узнал приложение.

## Что умеет

- Коды и подписки: выбор региона → номинал → панель «Купить».
- Приложения: поиск, категории, множественный выбор (запоминается между запусками),
  пакетная цена (5 любых — 1 790 ₽) и скидки за количество считаются автоматически.
- Выбор приложений: один тап — галочка и приложение в наборе, ещё тап — убрано. Карточка
  «Ваш набор: 3 из 5» (прогресс и иконки выбранных) открывает меню набора: тап по приложению
  убирает его, пустой слот возвращает к выбору, внизу итог, «Очистить» и «Оформить».
- Подписка Telegram Premium требует @username — он проверяется перед заказом.
- Заказы хранятся на устройстве: можно отменить, написать менеджеру по конкретному заказу.
- Реферальная программа: ссылка с ID пользователя; кто пригласил — запоминается и
  добавляется в сообщение менеджеру («Пригласил: ref_123»).
- Кнопка «Назад» Telegram, тактильный отклик, закрытие шторок свайпом вниз.

## Как работает заказ

Оплаты внутри приложения нет. «Купить» → «Оформить заказ» сохраняет заказ на телефоне
(вкладка «Заказы») и открывает чат с менеджером с готовым сообщением: номер заказа,
товар, сумма. Менеджер присылает способ оплаты и выдаёт код/доступ.

Для автоматической оплаты (ЮKassa / Telegram Payments), автовыдачи кодов,
синхронизации заказов между устройствами и реальной статистики рефералов нужен бот
с сервером — это следующий этап.

## Запуск локально

```bash
python -m http.server 5190
```

## Публикация

Любой HTTPS-хостинг (GitHub Pages, свой домен). Ссылку указать в @BotFather →
бот → Bot Settings → Menu Button (с `https://` в начале).
